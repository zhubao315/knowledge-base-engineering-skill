# Knowledge Lifecycle L0–L7

| 阶 | 产物 | 判定标准 | 典型病 |
|---|---|---|---|
| L0 原始输入 | 摘录、划线、剪藏、原文 | 能指出出处与时点；不含自己的判断 | 收藏即终点 |
| L1 概念 | 术语定义 | 说清“是什么、不是什么、与谁相邻”；有源 | 抄百科，无边界 |
| L2 模型 | 变量与因果的简化表达 | 写得出“输入 → 机制 → 输出”，标适用条件 | 把比喻当模型 |
| L3 框架 | 多个模型的组织 | 列得出部件与装配顺序 | 把目录当框架 |
| L4 原则 | 可迁移判断准则 | “当……时，优先……，除非……” | 口号化 |
| L5 洞察 | 从多个源提炼的新联系 | 连接两个此前无关的源，能预测未见情形 | 读后感 |
| L6 晶体 | 自包含、可独立成立的高价值洞察 | 脱离上下文仍成立；有调用示例与边界 | 长篇大论 |
| L7 技能原子 | 可直接装载执行的规范 | 触发、步骤、验收、回滚、升级五段 | 经验留在脑子里 |

## 五步定级

1. **定级**：按产物定，不按主题定。
2. **溯源**：source 原件是否存在、可打开、有时点。
3. **写调用**：调用示例 + 边界约束。
4. **连概念**：入链 ≥1、出链 ≥2。
5. **定去留**：L0/L1 源料；L2–L4 概念层；L5/L6 洞察层；L7 技能库。

## 保真度（设计口径）

Schema 完整性 35% + 引用可溯源 25% + 跨链接 ≥2 20% + 非镜像智慧 20%；单条 ≥70 分合格。分数只用于定位，不用于排名。

## 退役

- 退役不是删除：提炼合并 → 删原件 → 重映射 → 注释任务。
- 先搬价值，再删原件；先重映射，再复扫；最后注释任务。
- 同一家族只留 1 篇精选；入链增加比删除数量更能说明成功。
- 删除权不在 AI 权限集合内；只产出候选与软归档计划。

## 输出

分级清单、候选正本、提炼稿、原件去向台账；每条样本必须有级别、理由、证据、下一步。
