# Health Metrics

## 双分制

- **文件级**：frontmatter、断链、标签、同步冲突。管“格式有没有崩”。
- **内容级**：七性、占位、重复、孤岛、种子、空壳。管“东西活没活着”。
- 两个分不能换算；`6.15/7` 只是上下文七性的一维，不是内容级总分的百分比。

## 体检 12 项

1. 口径一致性
2. 全库笔记数
3. 断链（目标 / 引用双数）
4. 孤岛（总数 + 构成）
5. 重复（整段 / 近重复 / 同名 / 镜像）
6. 种子（启发式 / FM 标记）
7. 空壳与结构（thin / 缺 H1）
8. 占位符（模板 blocker / 内容债）
9. frontmatter 合规率（缺失 / 豁免 / 死引用）
10. 标签白名单（野生 / 标准）
11. 同步健康（冲突副本）
12. 上下文七性（七维 + 总分 + 样本数）

第 1 项不过，后 11 项只作参考。

## 上下文七性

原子性、显式关系、可溯源、时效、紧凑、隔离、可寻址。每项都要有定义、样本数、分项分。

## 口径四问

1. **口径**：算哪些目录、排除哪些文件。
2. **时点**：哪天测的。
3. **尺子断点**：工具改过吗；改过就分段比。
4. **构成里的豁免**：哪些对象按制度不计入。

四问顺序不能换。四问管话，八问管尺；工具改动、重大结论前跑满八问。

## 状态

`PASS` / `FAIL` / `NOT_RUN` / `BLOCKED` / `NEEDS_REVIEW`。`NOT_RUN` 与 `BLOCKED` 不得算 `PASS`。

## 阈值

阈值按自己的基线定：先跑四周，取中位数；新库可用绝对数，老库用比例；治理期收紧，稳态期放宽。任何阈值必须带版本、时点、范围和复算方式。
