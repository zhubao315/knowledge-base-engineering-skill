# O — Observe

> 先看清，再动手；假红灯比没红灯更危险。

## 这一段做什么

在动手之前，先看清真实：环境是否可达、有没有急症、库现在是什么状态。只读，不写。

## 1. 环境预检

- 探测 `KBE_SANDBOX_ROOT`（默认 `/app/.hermes/obsidian`），只检查 `exists` / `is_dir` / `readable`。
- 可达 → 沙箱分支；不可达 → 本地独立库分支。**不展示不可达路径，不抛路径错误。**
- 沙箱可达也只生成镜像/同步**计划**；实际同步交外部工具并由人批准。
- 本地默认 `para`，最小结构 `minimal`，分层结构 `ulife`。

## 2. 急症四联

先查有没有急症；有急症时只出处置卡，不进入普通体检。

| 急症 | 先做什么 | 验收信号 |
|---|---|---|
| 同步冲突副本 | 合并或恢复，只留一个正本 | 冲突副本为 0，正文完整 |
| 0 字节文件 | 从备份/历史恢复，或人工确认 | 文件非空，正文可读 |
| 野生标签 | 归入标准标签体系，保留原意 | 野生标签为 0，检索不丢 |
| 断链率 >10% | 先停写入，按高频到长尾修 | 高频清零，长尾有策略 |

顺序：停手 → 留证 → 回滚 → 复验。没有停止/备份/恢复工具时，只能输出指令，不能声称已执行。

## 3. 体检 12 项

按序跑，不跳项：

1. 口径一致性
2. 全库笔记数
3. 断链（目标数 + 引用数）
4. 孤岛（总数 + 构成）
5. 重复（整段 / 近重复 / 同名 / 镜像）
6. 种子（启发式 / 元数据标记双口径）
7. 空壳与结构（thin / 缺 H1）
8. 占位符（模板占位 / 内容债）
9. frontmatter 合规率（含豁免）
10. 标签白名单（野生 / 标准）
11. 同步健康（冲突副本）
12. 上下文七性

**第 1 项不过，后 11 项只作参考。**

## 4. 双分制

- **文件级**：格式、元数据、结构是否崩。
- **内容级**：七性、占位、重复、孤岛、种子是否活。
- 两者必须并报；只报文件级，就是把“格式没崩”说成“知识活着”。
- 基准口径：文件级 100 A+ / 内容级 92 A / 上下文 6.15/7（样本 10,023）。这是某次快照，不是行业标准。

## 5. 输出

- 环境报告：本地/沙箱、推荐 profile、可选模式。
- 急症分诊卡：命中项、影响范围、停手建议。
- 体检底稿：读数、时点、范围、证据。
- 异常清单：缺元数据、断链、孤岛、占位、重复。

## 停点

- 命中急症：只出应急四联，不进入普通治理。
- 环境不可达：降级本地，不抛路径错误。
- 无读取权限：`BLOCKED`，不猜内容。
- 第 1 项不过：后续读数只作参考。
