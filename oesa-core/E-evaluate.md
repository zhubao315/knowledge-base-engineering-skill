# E — Evaluate

> 先修尺子，再量库；挡住一条注水，比清掉一百条便宜。

## 这一段做什么

在入口处硬核评估：什么能进、什么必须拦下、什么只能挂起。脏数据不进，后面的推理才有意义。

## 1. G0–G7 准入闸门

| 门 | 查什么 | 判定线 | 不过怎么办 |
|---|---|---|---|
| G0 格式契约门 | title / created / tags；H1 唯一 | 缺一项即拒收 | 补全再入，或退回收件箱 |
| G1 拓扑锚定门 | 入链与出链 | 入链 ≥1、出链 ≥2 | 只进收件箱，补链后再入 |
| G2 反注水门 | 占位、空表格、空标题、套话结构 | 命中即挂起 | 模板占位当天清；内容债排期 |
| G3 单一来源去重门 | 与既有笔记相似度 | >0.88 强制合并 | 合并，或书面说明为何另立 |
| G4 种子半衰门 | 待扩充骨架年龄 | 30 天内三选一 | 扩充 / 合并 / 降级归档 |
| G5 索引同步门 | 改目录后的计数 | 声明数 = 实测数 | 重跑计数，对不上先停用该索引 |
| G6 单一正本门 | 同主题版本数 | 只留一个正本 | 合并或归档其余版本 |
| G7 红队事实一致门 | 确定性预测/策略 | 有反方核对记录 | 补证据，或降级为假设 |

八道门按顺序过，前一道不放行，后一道不看。G2/G4/G7 需要人判断；G3/G5/G6 依赖库内索引与去重实现。

## 2. 口径四问

每个头条数字必须回答：

1. **口径（统计范围与排除集）**：算哪些目录、排除哪些文件。
2. **时点**：哪一天、哪一次扫描。
3. **尺子断点**：规则/排除集是否改过，前后能否直接比。
4. **构成里的豁免**：哪些对象依规不参与判定。

缺一项，标“未校验”，不能写成结论。

## 3. 两套门正交

- 准入闸门 G0–G7：管进出。
- 三层质量门（格式 → 一致性 → 交叉）：管执行。
- 两套门分开报，不合并成一个绿灯；同源数据不能重复计入。

## 4. 输出

- 准入回执：门号、判定、拒收/挂起原因。
- 拒收与挂起清单：补什么、补完放哪里。
- 口径披露草稿：范围、时点、断点、豁免。

## 停点

- 不过门：只进收件箱或退修，不进入消化。
- 口径缺失：`NEEDS_REVIEW`，不下结论。
- 规则冲突：暂停，交规则所有者。
- 物理删除：不进入评估，因为不在权限集合内。
