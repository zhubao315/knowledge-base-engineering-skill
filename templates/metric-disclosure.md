# Metric Disclosure

```markdown
### 口径披露与度量声明

1. **时点与断点**：扫描执行于 `YYYY-MM-DD HH:MM`；最近一次规则校准日 `YYYY-MM-DD`，跨期对比以此为断点，前后不直接算增减。
2. **范围**：全库篇数采用【统计全量】（含归档，排除备份/媒体/运行时）；断链采用【断链来源】（排除归档出链 __ 篇）。
3. **自检等式**：统计全量（__）− 断链来源（__）= 归档区篇数（__）；校验：□ 通过 □ 异常。
4. **豁免**：FM 豁免 __ 篇；孤岛豁免：日记 __ / 归档 __ / 出版 __ / 核心域 __%。
5. **构成**：总数之外给拆解，禁止只报单数。
6. **工具版本**：尺子最近一次修改 `YYYY-MM-DD`，改了什么：__。
7. **数据性质**：□ 全量自动复扫 □ 故障期手工静态快照。
```

任何一项填不出，报告只能标“草稿”，不能对外。
